# 표준제조기준 검토

식품의약품안전처고시 제2026-57호(2026. 8. 6. 시행) 별표 1에 따른 검토 화면이다. 원문은 탭에서 조회할 수 있다.

- 함량은 제형에 맞는 단위당 값으로 입력한다. 경구제는 성인 1회량과 최대 복용 횟수를 곱해 1일량을 계산한다.
- 만 8~10세는 성인량의 ½, 만 11~14세는 ⅔를 비교한다. ⅔가 입력한 최소 투여 단위의 정수배가 아니면 만 8~14세에 ½을 적용하는 대안을 보여준다. 연령별로 명시된 하한과 참고용 환산 하한은 구분한다.
- OTC 공급조건에서 성분명이 해당 장의 표에 하나만 일치하고, 함량의 분모가 선택 제형과 일치할 때만 수치가 들어간다. 공급조건의 원문과 확인이 필요한 성분을 화면에서 확인할 수 있다.
- 판정은 구현된 자동 확인 항목에 적용된다. 제형·효능에 따른 예외와 시험값, 제산력, 소화효소 역가 등 개별 조건은 표시된 원문을 대조한다. 소아 환산 비교 화면은 만 8~14세 범위다.

검증은 'node --test tests/medicineStandard.test.cjs'로 실행한다. 별표의 HWPX 파일로 데이터를 갱신할 때는 이 폴더의 'build_catalog.py'에 원문 경로와 출력 파일 'annex.json'을 순서대로 전달하고 규칙·테스트를 함께 검토한다.
